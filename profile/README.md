# Engineering Assisted by Intelligent Systems (IASI)

IASI is an open ecosystem dedicated to exploring a new way of engineering.

We believe that the emergence of Intelligent Systems represents a paradigm shift comparable to the arrival of the Internet, object-oriented programming or open source software. This is not simply about adopting new tools, but about rethinking how we conceive, design, build and evolve software systems.

IASI exists to explore that journey.

---

# Our Approach

IASI does not start from a predefined methodology, we start from the problem, **without preconceptions**.

We believe that the emergence of Intelligent Systems requires us to rethink the way engineering is practiced. Therefore, we do not assume that existing methodologies, by themselves, provide the right answer.

Instead:

> **We do not adopt methodologies to solve problems. We start from problems to discover the methodology that best fits each one**.

Every need is evaluated independently.

- If an existing methodology provides the best answer, we will use it.
- If it needs to be adapted, we will adapt it.
- If combining multiple approaches provides a better solution, we will combine them.
- And when none of them is sufficient, we will build a new one, turning the resulting knowledge into a company asset or releasing it as open source.

We are not looking for a universal methodology.

We are looking for the best solution to every problem.

# Principles

- Engineering comes first.
- Intelligent Systems are engineering assistants.
- Knowledge should be open.
- Documentation is an engineering artefact.
- Automation should be the consequence of good design, not an objective by itself.
- Components should be reusable.
- Every decision can be questioned.
- Methodologies must evolve as well.

---

# The Journey Is Knowledge

IASI does not only publish results.

It also documents the journey.

- Architectural decisions.
- Experiments.
- Questions.
- Mistakes.
- Changes of direction.
- Discarded tools.
- Ideas that worked... and those that did not.

We believe that understanding **how** a solution is built is as valuable as the solution itself.

That is why, in IASI, the journey is part of the product.

---

# An Open Project

IASI started as a personal initiative, but it is not intended to remain a personal project.

It is designed to grow openly, incorporating new ideas, tools, methodologies and contributors.

**Well-founded contributions are always welcome.**

We believe that Engineering Assisted by Intelligent Systems can only emerge through collaboration, critical thinking and experimentation.
